Récupérer les assets depuis un agent IA

Chaque dessin existe en trois formes dans le dépôt : PNG, module JavaScript (pixels + PNG en data URL) et code source pxl. Tous les chemins sont relatifs à la racine du dépôt.

  1. Découvrir : lire library/catalog.json (catégories, familles, variantes, tailles, propriétés, chemins). Aucun pixel dedans, c'est léger.
  2. Charger : import { load, loadVariant, find, draw } from "./library/index.js", ou importer directement library/js/<catégorie>/<asset>.js.
  3. Utiliser : v.src (PNG en data URL), v.rows + v.palette (pixels lisibles), v.frames pour les animations, ou les fichiers library/png/… et les sprite sheets library/sheets/….

Guide complet : library/README.md et llms.txt à la racine du dépôt.
